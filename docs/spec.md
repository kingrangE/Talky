## 제품

  - 기존 자유 대화와 분리된 Talky Speaking Mock Test 모드
  - 중급~중상급 수험생 대상
  - 11문항·약 20분의 TOEIC® Speaking test 형식을 참고하되 모든 문제와 지시문은 자체 제작
  - 준비·답변 시간이 자동 진행되며 일시정지, 이전 이동, 재녹음 불가
  - 기술 오류만 재시도 가능하며 문항별 체크포인트로 10분 이내 복구
  - 시험 전 설명은 한국어, 시험 중 지시와 문제는 영어
  - 데스크톱 Chrome·Edge를 공식 지원

  ## 문제 생성 하네스

  - 시험 직전에 생성하지 않고 주기적으로 후보 세트를 일괄 생성
  - Blueprint → Item Writer → Asset Matcher → Rubric Builder → Critic → Adjudicator의 bounded agentic LangGraph
  - 생성 모델과 독립 심사 모델 사용
  - 결정론적 규칙 검사와 Agent 평가를 모두 통과해야 함
  - 자동 수정은 최대 2회이며 이후에는 폐기
  - 구조화된 판정·근거·버전·재시도 기록만 저장
  - 후보 세트, 검증 보고서, 라이선스 manifest를 GitHub PR로 검토
  - 사람이 승인하고 병합한 immutable 세트만 배포
  - 사진은 명확한 공개 라이선스 자산을 사용하고 저작자·URL·라이선스 기록
  - 일정표·안내문은 HTML/CSS 템플릿으로 생성
  - 안내 음성은 승인 시 Piper로 미리 생성하고 checksum 기록
  - MVP는 완주 가능한 11문항 세트 1개부터 시작

  ## 무료 로컬 채점

  - 유료 평가 API는 사용하지 않음
  - CPU 기본 프로필:
      - faster-whisper transcript
      - VAD, 발화시간, 침묵 비율, 말하기 속도
      - 로컬 Ollama 기반 언어·과업 평가
      - 발음은 명료도·유창성 추정치로 정직하게 표시

  - 고급 선택 프로필:
      - Wav2Vec2/GOPT 계열 음소 평가 모델
      - 별도 Docker 프로필
      - GPU가 감지되면 자동 가속하고 CPU에서도 기능적으로 동작

  - 공개 설치는 API 키 없이 동작해야 함

  ## 응답 평가 Agent

  - 음향 지표는 결정론적으로 추출
  - Language Quality Agent와 Task Fulfillment Agent가 전체 시험을 역할별 평가
  - 저신뢰·불일치 결과만 Evidence Verification Agent가 한 번 재검토
  - 그래도 불일치하면 점수 범위를 넓히고 신뢰도를 낮춤
  - 최종 Agent가 점수를 임의로 정하지 않음
  - 버전이 고정된 공개 공식이 구조화 평가치를 점수 범위로 집계
  - 무응답은 평가에 반영하지만 마이크·업로드 오류는 불이익 없이 재시도

  ## 결과

  - AI 예상 점수 범위 + 예상 등급 + 신뢰도 + 평가 프로필 + scoring_version
  - 초기 점수는 명시적으로 Beta
  - 공식 점수 비교 표본 30개 이상일 때만 새 보정 버전 배포
  - 사용자에게 최근 공식 점수와 응시일을 선택적으로 입력받아 익명 보정 통계로 사용
  - 문항 유형별 평가와 근거 발화 제공
  - 우선 개선점 3개 제공
  - 원래 의도를 보존한 최소 수정본과 목표 등급용 가상 모범 답안 제공
  - 분석은 한국어, 발화 인용과 예시는 영어
  - 90초가 지나면 가능한 결과부터 공개하고 실패 항목은 백그라운드 재시도
  - 실패 항목을 0점으로 처리하지 않으며 신뢰도에 반영

  ## 공개 데모와 개인정보

  - IP당 하루 1회, 전역 동시 시험 1개
  - 대기 화면에 예상 대기시간, 샘플 리포트, GitHub 링크 표시
  - 브라우저 MediaRecorder 기반 자동 녹음 컴포넌트와 HTTPS 사용
  - 원본 음성은 명시적 동의 후 암호화 저장
  - 음성 사용 목적은 채점, 자동 재시도, 오류 분석으로 제한
  - 모델 학습이나 사용자 재생에는 사용하지 않음
  - 음성·transcript·개인 리포트는 72시간 후 자동 삭제
  - 완주율·처리시간·점수 구간 등 비식별 집계 통계만 장기 보관
  - 익명 사용자는 서명된 비밀 URL로 72시간 동안 결과 재접근 가능
  - 현재 단일 anonymous 사용자 구조는 방문자별 격리 구조로 교체
